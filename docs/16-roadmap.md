# 16. Roadmap и расширение

Список направлений развития, на которые шаблон **уже подготовлен**.
Каждый пункт — это разумная задача на 0.5–3 дня для опытного разработчика.

## Геймплей

- **Бустеры**: бомба, линейный, цветной. Добавить `Tile.kind` и обработку
  в `cascade` + анимации “создания бустера” при матче длиной ≥4.
- **Препятствия**: камни (ломаются от соседнего матча), лёд (требует
  2 удара), цепи. Это новые типы клеток + правила взаимодействия.
- **Цели уровня**: помимо счёта — “собрать N синих”, “освободить персонажа”.
  Расширяем `gameMachine` событиями цели.
- **Подсказки**: после паузы 5 сек подсвечиваем валидный своп. Требует
  функции `findFirstValidMove(board)`.
- **Перемешивание**: при отсутствии валидных ходов автоматически
  перемешиваем доску.

## Анимация и спецэффекты

- **Particle FX**: на каждое матч-удаление выбрасываем 4-8 частиц.
- **Screen shake**: на длинных каскадах и бустерах.
- **Tile bounce**: микро-анимация “взаимодействия с соседом” для тайлов
  рядом с матчем.
- **Skeletal Spine**: для крупных артов и кат-сцен.

## Контент

- **Атласы тайлов**: подготовить TexturePacker-конфиг и pipeline.
- **Анимированные тайлы**: 3-4 кадра pop-анимации.
- **Музыка**: 1-2 фоновых трека, переключение между сценами.
- **Локализация**: i18n-пакет (например, `@formatjs/intl`).

## Метаигра

- **Карта уровней**: React-страница до начала игры, прогресс по узлам.
- **Сохранение**: zustand `persist` middleware → localStorage.
- **Очки и звёзды**: 1/2/3 звезды по порогам счёта.
- **Прохождение целей**: серии, дневные награды.

## Платформа

- **PWA**: манифест, service-worker, offline-режим.
- **Капсула в WebView (Telegram, ВК)**: настройка viewport, шрифтов,
  обхода жестов.
- **Capacitor**: упаковка в нативное приложение для iOS/Android.

## Производительность

- **Web Worker для тяжёлых операций**: `findFirstValidMove`,
  процедурная генерация уровней.
- **GPU instancing**: для больших полей частиц.
- **Offscreen canvas**: рендер в фоне в воркере (экспериментально).

## Инструментарий

- **Editor уровней**: drag-n-drop UI в `dev`-режиме, экспорт в JSON.
- **Debug overlay**: счётчики FPS, draw calls, count tiles.
- **Storybook**: для UI-компонентов (HUD, кнопки, модалки).
- **Сбор аналитики**: PostHog / Amplitude через event-bus.

## Тестирование

- **Vitest + helpers**: фабрики для досок, ассерты для матчей.
- **Playwright**: smoke + visual regression.
- **CI**: lint, type-check, unit, build, deploy preview.

## Безопасность и стабильность

- **Sentry**: ловить ошибки в проде.
- **Версии**: добавить версионирование `Board`-схемы для миграций
  сохранений.
- **Анти-чит**: серверная валидация для лидерборда (если будет).

## Краткосрочный фокус для проекта заказчика

1. **Готовая база (этот шаблон)** — есть.
2. **Реальные арты** + атлас тайлов.
3. **Бустеры и цели уровня** (приоритет 1).
4. **3-5 уровней** для пилота.
5. **Эффекты**: ParticleContainer + Spine.
6. **Производительность**: профилирование на 3-х устройствах.
7. **Тесты**: критичный матчер, каскад, перемешивание.

## Долгосрочный фокус

- **Метаигра** (карта, прогресс).
- **Многоязычная локализация**.
- **Сетевая часть**: leaderboard, события.
- **Расширение жанра**: физический режим (Matter активно используется).
