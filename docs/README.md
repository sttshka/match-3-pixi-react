# Документация — Match-3 на Pixi v8 + React

Эта документация — единый источник знаний по проекту-шаблону для match-3 игры
на стеке **Pixi.js v8 + React 18 + @pixi/react v8 + Matter.js**.

Документация подготовлена в формате “читается сверху вниз”, но каждый раздел
самодостаточен и может быть открыт независимо.

## Соглашения

- Все термины (Board, Tile, Cascade) пишутся с заглавной — это **доменные сущности**.
- Везде, где видите `[см. п.N]`, имеется в виду номер документа в этом каталоге.
- Сниппеты кода намеренно сокращены — для полного контекста смотрите файлы в `src/`.

## Кому это нужно

- **Геймдеву**, который начинает match-3 проект на Pixi v8 и хочет видеть
  работающую архитектуру с самого начала.
- **Тимлиду**, которому нужен материал для онбординга разработчиков.
- **Консультанту** (вам, если вы готовите ответы для заказчика) — здесь собраны
  ответы на типовые вопросы по best practices, оптимизации и интеграции.
- **AI-агенту** (Cursor, Codex, Claude Code) — основной вход для агента
  это `AGENTS.md` в корне, оттуда есть ссылки сюда. Документация в `docs/`
  написана компактно, чтобы агент мог подгружать только нужный раздел и
  экономить контекст.
